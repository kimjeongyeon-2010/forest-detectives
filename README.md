숲속 탐정단 · Forest Detectives
색깔 구역마다 숨어 있는 숲속 친구를 논리만으로 찾아내는 추리 퍼즐이에요. 혼자 실력을 키우거나, 친구 2~4명과 같은 퍼즐로 속도 대결을 펼칠 수 있어요.

규칙
색깔 구역, 가로줄, 세로줄마다 친구가 딱 한 마리씩 있어요.
친구끼리는 대각선을 포함해 붙어 있을 수 없어요.
한 번 탭하면 × 표시, 두 번 탭하면 친구 찾기. 없는 칸을 고르면 기회가 하나 줄어요.
난이도
난이도	크기	기회	힌트	필요한 추리
이지 · 새싹 숲	7×7	5	3	남은 칸 찾기, 한 줄에 갇힌 구역
노멀 · 깊은 숲	9×9	3	2	여러 구역을 묶어 보는 추리
하드 · 비밀의 숲	10×10	3	1	가정해 보고 모순 찾기까지
모든 퍼즐은 정답이 하나뿐이고, 추측 없이 논리만으로 풀리도록 미리 검사했어요.

온라인 대결
방 만들기 → 초대 링크 복사 → 친구에게 보내기. 친구는 링크를 열고 이름만 적으면 바로 들어와요.
로그인이나 설치가 필요 없어요. 친구들의 기기가 서로 직접 연결돼요(WebRTC, 공개 Nostr 릴레이로 서로를 찾아요).
일부 학교·회사 와이파이에서는 기기 간 직접 연결이 막혀 있을 수 있어요. 그럴 땐 집 와이파이나 모바일 데이터로 접속해 주세요.
