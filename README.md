# 숲속 탐정단 · Forest Detectives

색깔 구역마다 숨어 있는 숲속 친구를 **논리만으로** 찾아내는 추리 퍼즐이에요.
혼자 스테이지 1~500에 도전하거나, 친구 2~4명과 같은 퍼즐로 속도 대결을 펼칠 수 있어요.

## 규칙
1. 색깔 구역, 가로줄, 세로줄마다 친구가 딱 한 마리씩 있어요.
2. 친구끼리는 대각선을 포함해 붙어 있을 수 없어요.
3. 한 번 탭하면 × 표시, 두 번 탭하면 친구 찾기. 없는 칸을 고르면 기회가 하나 줄어요.

## 스테이지 (혼자 하기)
스테이지 1부터 500까지, 깰 때마다 다음 스테이지가 열려요. 같은 장 안에서도 뒤로 갈수록 더 깊은 추리가 필요해요.

| 장 | 스테이지 | 보드 | 기회 | 힌트 |
|---|---|---|---|---|
| 1장 새싹 길 | 1–20 | 5×5 | 5 | 3 |
| 2장 이끼 언덕 | 21–60 | 6×6 | 5 | 3 |
| 3장 개울가 | 61–120 | 7×7 | 5 | 3 |
| 4장 깊은 숲 | 121–200 | 8×8 | 4 | 2 |
| 5장 안개 계곡 | 201–300 | 9×9 | 3 | 2 |
| 6장 달빛 숲 | 301–400 | 10×10 | 3 | 1 |
| 7장 비밀의 숲 | 401–500 | 10×10 | 3 | 1 |

실수와 힌트 없이 깨면 별 3개예요.

## 회원가입 · 로그인
- 오른쪽 위 **로그인**에서 아이디(영문 소문자·숫자·밑줄 4~16자)와 비밀번호(6자 이상)로 가입해요.
- 로그인하면 스테이지 기록이 계정에 저장돼서 다른 기기에서도 이어서 할 수 있어요. (Firebase Authentication + Cloud Firestore)
- 비밀번호는 되찾을 수 없으니 꼭 기억해 두세요.

## 온라인 대결 난이도
| 난이도 | 크기 | 기회 | 힌트 | 필요한 추리 |
|---|---|---|---|---|
| 이지 · 새싹 숲 | 7×7 | 5 | 3 | 남은 칸 찾기, 한 줄에 갇힌 구역 |
| 노멀 · 깊은 숲 | 9×9 | 3 | 2 | 여러 구역을 묶어 보는 추리 |
| 하드 · 비밀의 숲 | 10×10 | 3 | 1 | 가정해 보고 모순 찾기까지 |

모든 퍼즐은 정답이 하나뿐이고, 추측 없이 논리만으로 풀리도록 미리 검사했어요.

## 온라인 대결
- **방 만들기** → **초대 링크 복사** → 친구에게 보내기. 친구는 링크를 열고 이름만 적으면 바로 들어와요.
- 로그인이나 설치가 필요 없어요. 친구들의 기기가 서로 직접 연결돼요(WebRTC, 공개 Nostr 릴레이로 서로를 찾아요).
- 일부 학교·회사 와이파이에서는 기기 간 직접 연결이 막혀 있을 수 있어요. 그럴 땐 집 와이파이나 모바일 데이터로 접속해 주세요.
